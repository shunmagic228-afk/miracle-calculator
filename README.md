# 電卓

iPhone向けの通常計算・日時マジック電卓です。ビルド不要の静的Webアプリです。

## 使い方

- 起動時は毎回マジックON。
- 右上の電卓アイコンで10秒〜5分後を10秒刻みで設定。設定時間は保存され、次回起動時も引き継ぎます。
- 計算開始前に%でマジックON/OFF。%の左上の丸の中の点がONの目印。
- 1回目の＝は通常の計算結果。自動入力準備完了時は7の下に点を表示。
- 次のタップで必要な＋/−を表示。その次からタップごとに必要な数字を入力。
- 入力完了後は＝以外無効。＝で1回目の＝の時刻＋設定時間の日時（MMDDHHmm）を表示。
- 日時表示後はAC以外無効。ACは計算だけリセットし、モードを維持。

## 公開・オフライン

GitHub Settings → Pages → Deploy from a branch → main / (root) → Save。
HTTPSで一度開き、設定のオフライン準備完了を確認後、Safariの共有からホーム画面に追加します。機内モードで起動・演技を確認してください。

## テスト

Node.jsで `node tests/engine.cjs` を実行。
